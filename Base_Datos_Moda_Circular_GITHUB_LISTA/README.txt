BASE DE DATOS INTERACTIVA — MODA CIRCULAR

Publicación con GitHub Pages
1. Descomprime este ZIP.
2. En tu repositorio https://github.com/Nini-nise/moda-circular-bga, pulsa Add file > Upload files.
3. Sube index.html y confirma con Commit changes.
4. Abre Settings > Pages. En Build and deployment selecciona Deploy from a branch, branch main y folder /(root), y pulsa Save.
5. Espera a que GitHub Pages publique el sitio; el enlace aparecerá en Settings > Pages.

El archivo index.html es autónomo: no necesita carpetas ni instalar dependencias.
Por privacidad, los campos de nombres, correos, marcas temporales y barrios se vaciaron en la versión pública. Las respuestas agregadas y las gráficas se conservan.
